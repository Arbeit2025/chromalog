# chromalog

今日の色ログ ― 1日を、1色で記録する日記ツール。

## 機能
- 月カレンダー表示（前月・次月への移動つき）。各日のセルに、記録した色とひとことメモが並ぶ
- 日付をクリックすると編集エリアが開く
  - カラーピッカー（`input[type=color]`）で自由に色を選べる
  - プリセットカラー30色（色名つき）からワンタップで選択も可能
  - 「今日のことば」としてひとことメモ（60字まで）を添えられる
  - 保存・削除ボタン
- カレンダーの下に今月のまとめを表示（記録した日数と、よく使った色）
- 記録はブラウザの localStorage（キー `chromalog-v1`）にのみ保存され、サーバーには送信されない

## データについて
- 保存形式は `{ "YYYY-MM-DD": {"color": "#rrggbb", "memo": "..."} }` という JSON。
- プリセットカラーはアプリ側で定義した30色で、ページに埋め込んで JavaScript から利用する。

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```
